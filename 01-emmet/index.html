01-Emmet

Plugin for faster HTML and css coding.

01-Child >

Creates child elements (nesting)

Example:

ul>li>a

Result:

<ul> <li><a href=""></a></li> </ul>

02-sibling +

Creates sibling elements

Example:

header+section+footer

Result:

<header></header> <section></section> <footer></footer>

03-multiplicacion *

Creates sibling elements

Example:

ul+li*3

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Atributo Clase .

Creates sibling elements

Example:

div+contenedor

Result:

<div class="contenedor"></div>

05-Multiples Clases ...

Creates sibling elements

Example:

div.clase1.clase2.clasen

Result:

<div class="clase1 clase2 clasen"></div>

06-Atributo Identificador #

Creates sibling elements

Example:

nav#menu

Result:

<nav id="menu"></nav>

07-Adicionar Texto {}

Creates sibling elements

Example:

div{Lorem Ipsum Dolor}

Result:

<div>Lorem Ipsum Dolor</div> <a href=“”>Click Aquí</a>

08-Personalizar Atributos []

Creates sibling elements

Example:

a[href=www.google.com]

Result:

<a href="www.google.com"></a>

09-Números Consecutivos $

Creates sibling elements

Example:

ul>li.num$*3

Result:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Dirección Números Consecutivos @-

Creates sibling elements

Example:

ul>li.num$@-*3

Result:

<ul> <li class="num3"></li> <li class="num2"></li> <li class="num1"></li> </ul>

11-Base Números Consecutivos @n

Creates sibling elements

Example:

ul>li.num$@3*4

Result:

<ul> <li class="num3"></li> <li class="num4"></li> <li class=“num5"></li> <li class=“num6"></li> </ul>

12-Subir Nivel ^

Creates sibling elements

Example:

section>article>div^p

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Agrupar ( )

Creates sibling elements

Example:

(header>nav)(section>article)

Result:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Generar “Lorem Ipsum Dolor” lorem

Creates sibling elements

Example:

lorem20
lorem
lorem*5

Result:

Lorem ipsum dolor sit amet.

15-Documents HTML html:

Creates sibling elements

Example:

html:xs —— Documento xhtml 1.0 Strict html:xt —— Documento xhtml 1.0 Transitional html:4s —— Documento html 4.01 Strict html:4t —— Documento html 4.01 Transitional html:5 —— Documento html 5

Result:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>Document</title> </head> </html>

16-Meta TAGS meta

Creates sibling elements

Example:

meta:vp ——

Result:

<metac="width=device-width, initial-scale=1.0">
